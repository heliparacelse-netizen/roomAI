# roomAI
🏠 roomAI

roomAI est une plateforme web d’aménagement intérieur par intelligence artificielle.
L’utilisateur importe une photo de sa pièce, l’IA analyse la scène, reconstruit la pièce en 3D temps réel et permet d’appliquer différents styles de design via un modèle Freemium / Premium.

✨ Fonctionnalités
🎨 IA & 3D

Analyse d’image (Vision IA via Hugging Face)

Détection automatique du type de pièce

Reconstruction 3D temps réel (Three.js)
